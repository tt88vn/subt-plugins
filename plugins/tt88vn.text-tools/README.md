# Text Tools

Commands for the selection (⌘ Command Palette → “Text: …” / “Văn bản: …”):

| Command | Example |
|---|---|
| camelCase / PascalCase / snake_case / CONSTANT_CASE / kebab-case | `user name id` → `userNameId`, `UserNameId`, `user_name_id`, `USER_NAME_ID`, `user-name-id` |
| Base64 Encode / Decode (UTF-8) | `Xin chào` ⇄ `WGluIGNow6Bv` |
| URL Encode / Decode | `a b&c` ⇄ `a%20b%26c` |
| Escape / Unescape JSON string | `say "hi"⏎` ⇄ `say \"hi\"\n` |
| Statistics | lines · words · characters of the selection or file |

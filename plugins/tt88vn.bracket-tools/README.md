# Bracket Tools

Phần "điều khiển ngoặc" của BracketHighlighter cho SubT. (SubT đã tự tô sáng cặp ngoặc tại con trỏ; API plugin chưa cho
vẽ lên gutter nên plugin này không tô màu.) Ngoặc nằm trong chuỗi và comment được bỏ qua theo ngôn ngữ của tệp.

| Lệnh (`Ngoặc: …` / `Brackets: …`) | Phím |
|---|---|
| Nhảy tới ngoặc tương ứng (bấm lại để quay về) | `Ctrl+M` |
| Chọn trong ngoặc / nháy — bấm tiếp: gồm cả ngoặc → ngoặc cha… | `Ctrl+Alt+[` |
| Cho biết ngoặc tương ứng ở dòng nào (khi nó nằm ngoài màn hình) | `Ctrl+Alt+]` |
| Xóa cặp ngoặc / nháy bao quanh | — |
| Đổi loại ngoặc / nháy bao quanh… (`(` `[` `{` `<` `"` `'` `` ` ``) | — |
| Bọc vùng chọn bằng ngoặc / nháy… | — |
| Tìm ngoặc không khớp (danh sách, chọn để nhảy tới) | — |
